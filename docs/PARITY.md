# Parity: Python netportal -> Rust

One table per area: every feature of the Python version (`docs/INVENTORY.md`, section numbers in
brackets), its status and the tests that prove it. Status values: **ported+tested**, **ported**
(no test yet), **not yet**, **deviation** (deliberate, see "Deliberate deviations" below; the
feature exists, its observable behaviour differs on purpose). Test names are
`crate::module::tests::name` for unit tests and `crate/tests/file.rs::name` for integration
tests; database tests need `NETPORTAL_TEST_DATABASE_URL` (`tools/test-db.sh`).

Later agents: tick your area off here, keep the feature list complete, and add every behaviour
change to "Deliberate deviations" with what, why and impact.
